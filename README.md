# 📊 Revenue Signal Tracking & Performance Analysis

## 🔍 Overview
This project analyses sales performance data to track revenue signals and uncover patterns impacting business outcomes. The objective was to move beyond static reporting and identify trends, inconsistencies, and performance drivers across key dimensions.

## 🎯 Problem Statement
Business reporting often provides visibility into metrics but lacks clarity on how performance varies across segments and over time, making it difficult to identify growth patterns and areas requiring attention.

## ⚙️ Approach
- Structured sales data using SQL for analysis  
- Evaluated performance across time, region, and product segments  
- Analysed trends and patterns to identify inconsistencies in growth  
- Designed a Power BI dashboard to visualise KPIs and performance signals  

## 📊 Key Insights
- Revenue performance varies significantly across regions and segments  
- Certain periods show inconsistent growth patterns impacting overall performance  
- Tracking performance signals across dimensions improves visibility into trends  

## 🚀 Outcome
- Improved visibility into sales performance and KPI trends  
- Enabled structured, data-driven business reporting  
- Provided a foundation for identifying areas requiring deeper analysis
