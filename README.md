# 📊 Sales Performance Dashboard (Power BI)

## Overview
This project is an interactive Sales Performance Dashboard built using Power BI. It helps analyze revenue trends, product performance, and key business KPIs to support data-driven decision making.

## Objective
To visualize sales data and identify business insights such as revenue trends, top-performing products, and regional performance.

## Tools Used
- Power BI
- Microsoft Excel

## Key Insights
- Sales and revenue trend analysis over time  
- Identification of top-performing products/categories  
- Region-wise performance comparison  
- KPI tracking (Revenue, Orders, Profit)

## Project Preview
Screenshots of the dashboard are available in this repository.

## Business Value
This dashboard helps in understanding sales performance patterns and supports strategic decision-making for improving revenue and operations.
