# 📊 Sales Performance Analysis Project (Power BI + SQL)

## 📌 Problem Statement
Businesses need clear visibility into sales performance to understand revenue trends, product performance, and regional growth patterns. This project analyzes sales data to extract actionable business insights.

---

## 🎯 Objective
To build an end-to-end analytics solution using SQL and Power BI to:
- Analyze sales performance
- Identify revenue trends
- Evaluate product and regional performance
- Support data-driven decision-making

---

## 🧰 Tools Used
- SQL (Data exploration & analysis)
- Microsoft Excel (Data preparation)
- Power BI (Data visualization)

---

## 📂 Project Workflow
1. Imported raw sales dataset
2. Performed data exploration using SQL queries
3. Identified key metrics (Revenue, Profit, Orders)
4. Built interactive Power BI dashboard
5. Derived business insights from visual analysis

---

## 📊 Key Insights
- Identified top-performing products by revenue
- Analyzed region-wise sales distribution
- Tracked overall revenue trends over time
- Evaluated category-wise performance
